# Từ vựng tiếng Anh

Ứng dụng web học từ vựng tiếng Anh theo ngữ cảnh (lớp học, nhà hàng, cơ quan, sân bay, khách sạn, mua sắm, giao tiếp hằng ngày). Cài lên màn hình chính của điện thoại bằng Safari (iPhone) hoặc Chrome (Android).

Các tệp: `index.html` (giao diện), `words.js` (dữ liệu từ vựng), `sw.js` (chạy nền, bộ nhớ đệm), `manifest.webmanifest`, `icon.svg`, `apple-touch-icon.png`.
